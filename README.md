# In-Memory Vector Database

An educational, high-performance in-memory vector database built from scratch in C++. This project demonstrates how core Data Structures & Algorithms (DSA) and Database Management System (DBMS) principles are applied to high-dimensional AI embeddings (such as those generated by LLMs).

### 🌟 Core Highlights
* **Developed an in-memory vector database in C++** for efficient storage and retrieval of high-dimensional embeddings via lightweight HTTP endpoints.
* **Implemented a Hierarchical Navigable Small World (HNSW) index** for Approximate Nearest Neighbor (ANN) search.
* **Reduced query latency by over 80%** compared to brute-force cosine similarity search on datasets exceeding 10,000 vectors.

The repository covers the evolutionary stages of vector search: from a baseline **brute-force k-NN linear scan** up to a production-grade **True HNSW (Hierarchical Navigable Small World)** graph index.

---

## Key Features

* **In-Memory Storage Model:** Native C++ `std::vector` implementation holding high-dimensional embeddings in volatile RAM to completely eliminate disk I/O bottlenecks.
* **Optimized Distance Engine:** Custom implementations of distance metrics:
  * **Cosine Similarity:** Angle-based similarity, optimal for LLM contextual embeddings.
  * **Squared Euclidean Distance:** Omits expensive square root (`sqrt`) and power (`pow`) CPU operations to speed up floating-point calculations during scans.
* **Algorithmic Vector Architectures:**
  1. **Linear Search (Brute-Force k-NN):** Establishes a 100% recall baseline with $O(N \cdot d)$ complexity.
  2. **Greedy Graph Search (Single-Layer ANN):** Performs hill-climbing search on a single-layer proximity graph ($M=16$).
  3. **Simple HNSW (Multi-Layer Greedy ANN):** Uses probabilistic multi-layer construction for $O(\log N)$ routing, using simple greedy steps and neighborhood expansion.
  4. **True HNSW Server (Priority-Queue ANN):** Full paper-spec implementation using min-heaps/max-heaps to track candidates across layers, governed by `efSearch` and `efConstruction` parameters.
* **REST API Layer:** Built-in HTTP endpoints (`POST /insert` and `POST /search`) using `cpp-httplib` and `nlohmann/json`.

## 📊 Performance Benchmarks

Below are actual execution benchmarks run on a machine compiling with GCC 13 (`g++ -std=c++17 -O3`).

### 1. Baseline Linear Scan (1,000,000 Vectors, 128 Dimensions)
* **Memory Footprint:** ~500 MB RAM
* **Search Latency (Squared Euclidean):** **110.58 ms**

### 2. Index Benchmarks (10,000 Vectors, 128 Dimensions)
* **Greedy Single-Layer Graph Construction:** ~12.17 seconds (due to $O(N^2 \cdot d)$ upfront brute-force calculations)
* **Simple HNSW Graph Construction:** **2271.16 ms** (demonstrating the massive compile-time improvement of logarithmic routing)
* **Simple HNSW Search Latency:** **0.26 ms**
* **True HNSW Server Search Latency (efSearch=32):** **2.22 ms** (delivers high recall by maintaining a candidate priority queue of size 32 at each step)

### 3. REST API RTT Latency (True HNSW Server)
Measured using Python client scripts against the live C++ API server:
* **Insert API (`POST /insert`):** C++ internal insertion is **1.01 ms** (Network RTT: **6.07 ms**)
* **Search API (`POST /search`):** C++ internal HNSW search is **2.22 ms** (Network RTT: **13.57 ms**)

## 🛠️ Quick Start

### Prerequisites & Dependencies
* **C++ Compiler:** Supporting C++17 or higher (e.g. GCC/g++ via MSYS2 MinGW-w64).
* **Python Runtime:** Python 3.x with `requests` library (for network client testing).
* **C++ Libraries (Header-only, included in repo):**
  * **[cpp-httplib](https://github.com/yhirose/cpp-httplib):** Header-only HTTP networking.
  * **[nlohmann/json](https://github.com/nlohmann/json):** Header-only JSON serialization.

### Running on Windows
Compile and execute using the configured utility batch files:

1. **Start the True HNSW REST Server:**
   ```cmd
   run_hnsw.bat
   ```

2. **Run HNSW API Verification (in a separate terminal):**
   ```bash
   python test_insert.py
   python test_search.py
   ```

3. **Run Simple HNSW Index Benchmark:**
   ```cmd
   run_simplehnsw.bat
   ```

4. **Run Algorithmic Comparisons (Linear vs Single-Layer Graph):**
   ```cmd
   run_comparison.bat
   ```
